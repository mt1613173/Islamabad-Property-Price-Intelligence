# 🏡 Islamabad Property Price Intelligence Platform

A full-stack **AI-powered Property Price Intelligence Web Application** designed to analyze and predict residential property prices in **Islamabad, Pakistan**. The platform leverages machine learning and data analytics to help buyers, sellers, and investors make informed real estate decisions through interactive dashboards, price prediction, property comparison, and market insights.

This project combines a modern web interface with a Python backend to deliver accurate property valuation and intelligent recommendations based on real-world housing data.

---

## 🚀 Features

### 📊 Interactive Dashboard

* Overview of property market insights
* Key performance metrics
* Visual representation of property trends

### 💰 Property Price Prediction

* Predict estimated property prices
* Input custom property details
* AI-powered valuation model

### 🔍 Property Value Checker

* Evaluate the market value of existing properties
* Compare predicted and expected prices
* Quick property assessment

### ⚖️ Property Comparison

* Compare multiple properties side by side
* Analyze price differences
* Compare size, location, and features

### 📈 Market Explorer

* Explore available housing data
* Analyze market trends
* Discover high-value investment areas

### 🎯 Smart Recommendations

* Receive intelligent property suggestions
* Identify investment opportunities
* Data-driven buying recommendations

### 📉 Performance Analytics

* Monitor machine learning model performance
* Display prediction accuracy metrics
* Evaluate system effectiveness

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/islamabad-property-price-intelligence.git
```

### 2. Navigate to the Project

```bash
cd islamabad-property-price-intelligence
```

---

## ▶️ Run the Backend

```bash
cd backend
pip install -r requirements.txt
python main.py
```

---

## ▶️ Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
